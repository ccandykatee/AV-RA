# AVÉRA — інтернет-магазин багатофункціональної косметики

Навчальний демонстраційний вебсайт бренду AVÉRA, створений на HTML, CSS та JavaScript.

## Структура

- `index.html` — структура сторінки та контент.
- `styles.css` — оформлення, адаптивність і стилі компонентів.
- `script.js` — фільтрація каталогу, кошик, збереження кошика у браузері та контактні форми.

## Як запустити локально

1. Завантажте або розпакуйте всі файли проєкту.
2. Відкрийте `index.html` у браузері.
3. Для зручнішої розробки можна відкрити папку у Visual Studio Code та запустити через розширення Live Server.

## Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на GitHub.
2. Завантажте `index.html`, `styles.css`, `script.js` і `README.md` у корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** оберіть **Deploy from a branch**.
5. Вкажіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Після публікації GitHub покаже адресу сайту в цьому ж розділі.

## Функціональність

- Адаптивне меню для мобільних пристроїв.
- Каталог із фільтрами за категоріями.
- Додавання товарів до кошика, зміна кількості та видалення.
- Збереження кошика в `localStorage`.
- Демонстраційне оформлення замовлення через поштову програму.
- Контактна форма через `mailto`.

## Важливо

Це фронтенд-прототип інтернет-магазину. Реальна оплата, обробка замовлень на сервері, база даних, облікові записи та надсилання форм без поштової програми не підключені. Для реального продажу потрібно додати серверну частину та платіжний сервіс.

Фотографії завантажуються з Unsplash, а шрифти — з Google Fonts, тому для їх відображення потрібне підключення до інтернету. Перед комерційним запуском перевірте ліцензії та права на використання зображень.
